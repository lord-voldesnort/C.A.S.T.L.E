## Brand & Style

This design system embodies an authoritative, battle-ready, premium cybersecurity posture built for uncompromising mission-critical operations. Inspired by modern aerospace telemetry, Tier-1 Security Operations Centers (SOC), high-assurance hardware consoles, and defensive fortress engineering, it prioritizes absolute visual clarity, cryptographic transparency, and unyielding precision.

### Aesthetic Foundation
- **Tactical Pitch-Black Substrate:** Pure zero-void black (`#000000`) acts as the bedrock canvas. Visual hierarchy relies on tight tonal surface steps (`#0A0A0A` through `#111111`) rather than hazy, washed-out grays.
- **Surgical Orange Accents:** A high-visibility fire orange (`#FF6A00`) acts as the visual sightline, deployed strictly for interactive focal points, tactical highlights, and focused verification states.
- **Instrument-Grade Restraint:** The visual language rejects gratuitous hacker cliches (blurry neon gradients, skull motifs, glowing circuits, playful puffy radii). Depth is asserted through ultra-crisp hairline strokes (`#1A1A1A`), mechanical corner notches, and deliberate information architecture.
- **Zero-Trust Transparency:** Cryptographic guarantees (local WebCrypto execution, zero network ingress/egress, Shannon entropy equations) are surfaced front and center as first-class UI citizens.

## Colors

The color palette operates strictly under an uncompromising high-contrast tactical dark environment. Pure black serves as the foundational substrate, eliminating any murky mid-tones.

### Palette Mechanics
- **Primary Accent (`#FF6A00`):** Tactical sightline fire orange. Demands immediate focus for primary actions, active input borders, live selection toggles, and state focus. Accompanied by `#FF7D1A` on hover and `#E55F00` under active compression.
- **Surface Tiers:**
  - `surface-root` (`#000000`): The base canvas background.
  - `surface-recessed` (`#050505`): Inset command lines, raw hex buffers, and inactive segmented button tracks.
  - `surface-base` (`#0A0A0A`): Structural panels and tool workbenches.
  - `surface-card` (`#0D0D0D`): Armor-plate interactive modules and parameter containers.
  - `surface-elevated` (`#111111`): Lifted inspection sheets, modal overlays, and elevated popovers.
- **Hairline Borders (`#1A1A1A`):** Defines rigid boundaries without diffusing light. Interactivity upgrades borders to `#262626` (rest/hover) or `#FF6A00` (focus/selected).
- **Semantic Status Signals:**
  - `status-verified` (`#10B981`): Cryptographic matches, valid HMAC tokens, and fortress-grade entropy.
  - `status-warning` (`#F59E0B`): Legacy digests (MD5/SHA-1), absent expiration claims, and suspicious URL subdomains.
  - `status-danger` (`#EF4444`): Tampered payloads, mismatched file digests, and catastrophic entropy vulnerabilities.
  - `status-info` (`#0EA5E9`): Diagnostic stream telemetry, URL query parameters, and metadata chips.

## Typography

The typography hierarchy balances technical authority with micro-level data density using three dedicated font families:

1. **Space Grotesk (Display & Architecture):** Imparts a structured, engineered presence to tool titles, module banners, and screen identifiers. Renders headers with high tension and deliberate geometric rhythm.
2. **Inter (Interface & Documentation):** Drives standard instructional passages, security rationales, and conversational memory prompts. Provides frictionless readability across dense parameter panels.
3. **JetBrains Mono (Telemetry, Code & Cryptography):** Mandated for all machine-readable output: SHA/MD5 digests, Base64URL JWT segments, AES cipher blocks, byte counters, keyspace values, and uppercase status badges (`MODULE // AUTH-01`). Eliminates ambiguity between glyphs (`0` vs `O`, `1` vs `l`).

## Layout & Spacing

The layout model is governed by a strict 4px mathematical grid that prioritizes situational awareness and structured density over sprawling whitespace.

### Grid & Breakpoints
- **Desktop (>=1024px):** 12-column fluid grid, max-width `1280px` (`max-w-7xl`), centered with `2.5rem` (`40px`) outer margin and `1.5rem` (`24px`) gutters. Tools feature 3-zone split layouts: Configuration (Left), Telemetry/Execution (Center), Output/Verification (Right).
- **Tablet (640px - 1023px):** 6-column grid with `1.5rem` margins and gutters. Side-by-side verification shutters and split canvases adapt into clean stacked 2-column or full-width groups.
- **Mobile (<640px):** Single-column stacked stream with `1rem` (`16px`) outer margins and gutters. Modals anchor to the viewport bottom with a `max-h-[92vh]` restraint and fixed header/footer utility bars.

### Spacing Cadence
- `space-xs` (4px): Inset micro-offsets, segmented button padding, and chip internal spacing.
- `space-sm` (8px): Icon-to-label gaps, badge paddings, and tight field clusters.
- `space-md` (16px): Standard form element padding, card inner gutters, and list item spacing.
- `space-lg` (24px): Major component separations, armor-plate internal margins, and grid gutters.
- `space-xl` (32px): Workspace module separation and section dividing thresholds.

## Elevation & Depth

This design system avoids blurry skeuomorphism, colored glass washes, and soft drop shadows. Visual depth is established through **tonal substrate stratification** and **localized collimated energy**.

### Depth Layers
1. **Bedrock Surface (`#000000`):** The ground level for all root views, page backgrounds, and backdrops.
2. **Recessed Substrate (`#050505`):** Pushed behind the surface plane. Used for terminal output fields, read-only hash buffers, and code inspection blocks. Framed with a 1px `#1A1A1A` inner stroke.
3. **Resting Modules (`#0D0D0D`):** Standard armor plates and tool cards. Outlined by a crisp 1px stroke of `#1A1A1A`.
4. **Elevated Overlays (`#111111`):** Modals, flyouts, and context menus. Depth is emphasized by a high-contrast dark occlusion shadow (`0 20px 48px -8px rgba(0, 0, 0, 0.85)`) paired with a `#262626` boundary stroke.

### Tactical Glow Architecture
Interactive focus and mission-critical verification inject restrained, high-intensity perimeter glows:
- **Primary Interactive Hover:** `0 0 16px -2px rgba(255, 106, 0, 0.25)` accompanied by a border transition to `#FF6A00`.
- **Verified Lock Glow:** `0 0 16px -2px rgba(16, 185, 129, 0.25)` along the verified banner boundary.
- **Critical Violation Glow:** `0 0 16px -2px rgba(239, 68, 68, 0.30)` signaling checksum mismatches or tampered signatures.

## Shapes

The shape system is strictly industrial and disciplined. Puffy, playful border radii are prohibited.

### Geometry Specifications
- **Base Corner Radius (4px / Soft Tier):** Standardized across buttons, inputs, segmented controls, status tags, and dialog bodies.
- **Card Radius (6px):** Exterior boundary for larger `.armor-plate` modules.
- **Pill Shapes (`rounded-full`):** Reserved exclusively for high-level category filters (`All Tools`, `Authentication`) and live binary radar indicators.
- **Tactical Notch (`.armor-plate`):** Primary interactive containers feature a signature architectural corner bracket: an absolute 8×8px marker positioned at `-1px, -1px` that renders a 2px top and left border in `#FF6A00`. This bracket remains dimmed at `opacity: 0.3` during rest, snapping to `opacity: 1.0` upon hover or child focus.

## Components

### Buttons & Action Triggers
- **Primary Action (`.btn-primary`):** Solid `#FF6A00` fill with pure `#050505` bold typography. Hover shifts background to `#FF7D1A` with a `0 0 16px rgba(255, 106, 0, 0.35)` glow; active press compresses to `#E55F00`. Border-radius is fixed at 4px.
- **Secondary Action (`.btn-secondary`):** `#0D0D0D` fill with 1px hairline border (`#262626`), high-contrast white text (`#FFFFFF`). On hover, border illuminates to `#FF6A00` and text gains subtle sightline tint.
- **Ghost Action (`.btn-ghost`):** Transparent background, `#888888` text. Hover shifts text to `#FFFFFF` with a subtle `#111111` surface fill.

### Input Fields & Monospace Buffers
- **Text & Secret Inputs:** Surface sits at `#050505` with a 1px `#1A1A1A` hairline border. Typography leverages `JetBrains Mono` 13px/14px. Focus state triggers a crisp 1px `#FF6A00` stroke and a `0 0 0 1px #FF6A00` ring. Placeholder copy is set to `#555555`.
- **Output Inspection Blocks:** Permanent read-only containers utilizing `#050505` backgrounds, 1px `#1A1A1A` border, copy button dock in top-right corner, and character/byte count telemetry displayed in `label-caps` at bottom-right.

### Dual-Metric Security Meters
- **Cryptographic Strength Meter:** 4-segment discrete horizontal bar displaying Shannon entropy tiers. Fills with `#EF4444` (Vulnerable), `#F59E0B` (Moderate), or `#10B981` (Fortress). Accompanied by a live `JetBrains Mono` entropy readout (e.g., `157 bits // FORTRESS`).
- **Human Memorability Meter:** Continuous progress track (2px height, `#1A1A1A` background) with a vibrant cyan (`#0EA5E9`) or emerald (`#10B981`) progress indicator detailing algorithmic recall probability.

### Unified Tabs & Segmented Switchers
- **Workspace Navigation:** Contained inside a `#050505` recessed strip with a 1px `#1A1A1A` border and 4px internal padding.
- **Tab State:** Inactive tabs use transparent backgrounds with `#888888` text. Active tab snaps forward with `#111111` background, 1px `#262626` outline, `#FFFFFF` text, and a bottom 2px `#FF6A00` indicator line.

### Status Callouts & Verification Shutters
- **Verified Verdict:** 1px solid `#10B981` border with a subtle `rgba(16, 185, 129, 0.08)` surface wash. Displays checkmark badge, cryptographic confirmation string, and key ID.
- **Violation / Tampered Alert:** 1px solid `#EF4444` border with `rgba(239, 68, 68, 0.08)` wash. Immediate visual callout detailing exact byte mismatch or broken HMAC signature.
- **Zero-Knowledge Privacy Banner:** Fixed tactical header strip on every tool (`#0A0A0A` substrate, 1px `#1A1A1A` border, `#888888` micro-mono text): `"100% Client-Side WebCrypto // Zero Server Storage // Zero Telemetry Ingress"`.
