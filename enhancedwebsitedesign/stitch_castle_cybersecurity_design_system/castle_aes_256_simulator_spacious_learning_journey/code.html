info Block Width vs Key Size Disambiguation
AES operates on standard 128-bit blocks (16 bytes). The term "AES-256" references the master key length (256 bits) and its resulting 14 transformation rounds, NOT the block width.

SECTION 6 // Diffusion, Scrambling & Key Injection

REMAINING ROUND PRIMITIVES

Following non-linear byte substitution, three complementary operations disperse byte interdependencies across the state and combine cryptographic entropy from the master key schedule.

STAGE 2 // DIFFUSION ROW OFFSETS
ShiftRows Operation

Bytes in the last three rows of the state matrix are cyclically shifted left by different offsets to disperse column-byte relationships:

Row 0: Shift 0 bytes[ b0, b1, b2, b3 ] ➔
Row 1: Shift 1 byte[ b5, b6, b7, b4 ] ⮌
Row 2: Shift 2 bytes[ b10, b11, b8, b9 ] ⮌
Row 3: Shift 3 bytes[ b15, b12, b13, b14 ] ⮌
Ensures bytes from each individual column intermingle across subsequent rounds.
