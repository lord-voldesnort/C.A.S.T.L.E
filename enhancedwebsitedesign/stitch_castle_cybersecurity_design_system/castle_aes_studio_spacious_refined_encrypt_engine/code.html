info HOW GCM COMBINES CONFIDENTIALITY AND INTEGRITY (AEAD) expand_more

Unlike legacy CBC mode which requires separate HMAC computation (Encrypt-then-MAC), Galois/Counter Mode computes authenticated encryption simultaneously. GCM uses standard CTR mode for data encryption and evaluates a universal polynomial over the Galois field GF(2^128) using the GHASH function to produce a 128-bit authentication tag.
