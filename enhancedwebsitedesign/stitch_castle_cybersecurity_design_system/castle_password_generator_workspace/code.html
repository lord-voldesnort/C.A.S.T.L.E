SECTION 08

Using Your Password Safely

Practical operational security protocols for credential hygiene.

01

1. Use a unique password for each account

Never reuse passwords across personal and enterprise accounts to prevent credential stuffing cascade attacks.

02

2. Store difficult passwords in a password manager

Use a reputable, air-gapped or end-to-end encrypted password manager rather than browser cache or plain notes.

03

3. Enable multi-factor authentication (MFA / FIDO2)

Enforce hardware security keys or authenticator apps wherever available for defense-in-depth protection.

04

4. Never enter credentials across unverified domains

Verify SSL certificates and complete domain names to protect against typosquatting and sophisticated spear-phishing.
