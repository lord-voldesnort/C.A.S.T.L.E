# DESIGN.md — Castle
# Overview
Castle is a premium cybersecurity platform inspired by the timeless principles of medieval fortifications and powered by modern cyber defense.
Castle is not another cybersecurity dashboard.
It is a digital fortress.
Every screen, interaction, animation, and component should reinforce protection, awareness, intelligence, and confidence. Users should feel like they are commanding an impenetrable fortress—not configuring software.
The interface combines:
- Modern Security Operation Centers (SOC)
- Military command centers
- Castle architecture
- Tactical UI systems
- Cyberpunk minimalism
- Enterprise software
The result should feel sophisticated, premium, and battle-ready.

# Premium Scroll-Down UI & Feature Design Specifications

To transition Castle into a state-of-the-art, premium single-page web app, the layout must be designed as a **continuous scroll-down tactical journey** rather than isolated page fragments. Each feature must look premium, utilize rich animations, and visually ground its functional parameters in the Castle metaphor.

## 🧭 Main Layout & Scroll Architecture

* **Continuous Tactical Journey**: The page acts as a vertical scrollable pipeline. Smooth CSS scroll-driven entry animations (using `fade-in-up` with scale, backdrop filters, and subtle border glows) reveal each module as the user scrolls down.
* **Watchtower Status Sidebar**: A sticky, glassmorphic vertical anchor navigation panel is pinned to the left screen boundary. It displays a minimalist tactical tree map of the castle's keeps:
  * `[SYSTEM STABLE]` (Global Health state)
  * `01. Watchtower Dashboard` (Status indicator)
  * `02. Cryptographic Vault` (AES Studio)
  * `03. Entropy Gate` (Password Creator & Analyzer)
  * `04. Fingerprint Scanner` (Hash Toolkit)
  * `05. Passport Verifier` (JWT Decoder & Verifier)
  * `06. Scout Patrol` (URL Phishing Analyzer)
  * Each anchor item shows a micro-glow on active scroll state, with custom line connectors tracing the scroll progress.

---

## 🛰️ Module 1: The Watchtower (Hero Dashboard)

* **UI Structure**: Pinned directly below the viewport hero header. A dashboard composed of modular tactical cards displaying system telemetry.
* **Features & Layout**:
  * **System Telemetry Grid**: Interactive nodes displaying simulated parameters (e.g. CPU load, active session key strength, client browser flags, local storage footprint).
  * **Interactive Quick-Launch Gate**: A central glowing compass/radar element. Moving the mouse over the radar sweeps a beam that highlights the surrounding module entrances, allowing users to click and scroll instantly to that segment.

---

## 🔒 Module 2: The Cryptographic Vault (AES Studio)

* **UI Structure**: A split workspace: the **Symmetric Forge** (Left) and the **Visualizer Keep** (Right), separated by a glowing vertical laser line.
* **Features & Layout**:
  * **The ECB vs. GCM Interactive Canvas Duel**:
    * Displays side-by-side rendering blocks. When an image is dropped, the ECB canvas encrypts block-by-block with a visible grid overlay. Identical blocks highlight with matching colors on hover, demonstrating pattern leakage.
    * The GCM canvas shows the image dissolving into absolute random white noise, accompanied by a flowing particle overlay representing the counter/IV incrementation.
  * **16-Byte Internal Round Visualizer**:
    * A central $4 \times 4$ grid of dark, metallic buttons containing the state matrix in hexadecimal.
    * **`SubBytes`**: Highlighted cells glow in deep orange. The hex values fade and morph into the S-Box value using a rapid numerical roll animation.
    * **`ShiftRows`**: An elegant sliding animation where the rows translate horizontally, wrapping around with a translucent trail showing the shifted bytes.
    * **`MixColumns`**: The columns of the matrix flash in blue, shrinking slightly and expanding in a "pressure pulse" motion to symbolize matrix multiplication.
    * **`AddRoundKey`**: Downward-streaming vertical light beams (XOR data stream) overlay the state grid as the subkey is combined.

---

## 🔑 Module 3: The Entropy Gate (Password Workspace)

* **UI Structure**: A dual-pane command screen.
* **Features & Layout**:
  * **The Power Core (Entropy Gauge)**:
    * A vertical cylinder indicator resembling a castle generator core. As the user types, the gauge fills with animated plasma.
    * Low entropy triggers a unstable, flickering red plasma field. High entropy (128+ bits) turns the core into a stable, glowing gold field with slow orbital rings.
  * **The Memory Forge (Memory-Assisted Wizard)**:
    * A clean, wizard-based panel presenting 3-5 inputs for the user's questions. 
    * When submitted, the answers are drawn into a central "forge" graphics block, stamped by a mechanical compression animation, and transformed into the deterministic SHA-256 base value.

---

## 🧬 Module 4: The Fingerprint Scanner (Hash Toolkit)

* **UI Structure**: A tactical drop-zone designed to look like a diagnostic terminal screen.
* **Features & Layout**:
  * **The Ingestion Bay (Drop Area)**:
    * A spacious card with dotted, pulsing borders. Dropping a file triggers a circular wave ripple expanding outward across the entire screen.
  * **Progressive Extraction (Chunked Progress)**:
    * Files are visualized as segmented tracks. For larger files, a scanner beam moves across the segments, lighting them up as the system hashes chunk-by-chunk. A real-time speed dial displays MB/s throughput.
  * **The Integrity Shutter (Hash Matcher)**:
    * When a user inputs a target hash to verify, the system splits into a dual verification grid. If they match, a green grid overlay locks into place with a mechanical clanking sound effect (visualized via a quick, snappy card lock-in animation). If mismatched, a red alert perimeter flashes.

---

## 🎟️ Module 5: The Passport Verifier (JWT Decoder)

* **UI Structure**: A three-pane wide-screen console that maps to the JWT structure: Header (Left), Payload (Center), Signature & Verifier (Right).
* **Features & Layout**:
  * **Syntax Alignment Sync**:
    * Each block matches its respective JWT segment color (e.g. Header is glowing purple, Payload is teal, Signature is gold). Hovering over a claim in the Center panel highlights the corresponding base64 string segment in the Left panel.
  * **Signature Status Panel**:
    * Shows a large, holographic security lock. When claims are valid, the lock glows green. Any edit to the payload claim immediately breaks the signature, turning the lock red with alert flags detailing the signature mismatch.
  * **"None" Algorithm Bypass Lab**:
    * If the token algorithm is modified to "none", the screen border flashes yellow warning stripes. An interactive drawer expands: **"Vulnerability Playground: Signature Bypass Detected"**, allowing users to see how older servers accepted unsigned tokens.

---

## 🔗 Module 6: The Scout Patrol (URL Phishing Analyzer)

* **UI Structure**: A targeting console layout resembling a perimeter scanner.
* **Features & Layout**:
  * **The Scanner Reticle**:
    * Entering a URL triggers a circular radar sweep animation. The URL string is parsed and printed in a large, spaced-out font.
  * **Perimeter Diagnostics Tree**:
    * **Punycode Spoofs**: Punycode segments (`xn--...`) are isolated in a floating overlay. Hovering reveals the spoofed character (e.g. `а` vs `a`) with a magnifying glass inspection block.
    * **Keyword Hijacking**: Connectors trace brand keywords found in subdomains back to the actual registered domain authority, highlighting discrepancies with a red dotted link.
    * **Port Breaches**: Non-standard ports glow with danger indicators, resembling an unlatched portcullis gate.
